# Flight Search

Compare flights and hotels across providers. Find the best prices, book via affiliate links. No markup, no tracking.

**Live:** https://flight-search.freeappstore.online

A free app on [FreeAppStore](https://freeappstore.online). App id: `flight-search`.

## Develop

```bash
pnpm install
pnpm dev
pnpm build
pnpm run typecheck
pnpm test
```

Before publishing, run `fas check` (`npm i -g @freeappstore/cli`). Pushing to `main` deploys the app.
